# 三角関数のグラフ ― 単位円から y = sinθ, y = cosθ へ

高校数学（数学II「三角関数のグラフ」）の授業用インタラクティブ教材。

**[index.html](index.html) をブラウザで開くだけで動きます。** 外部ライブラリもネット接続も不要なので、会場のネットワーク環境に左右されません。

## 何ができるか

左の単位円を指でなぞると、**なぞった分だけ右にグラフが描かれます**。自動では動きません。生徒に「ここまで回したら、グラフはどこまで描けるか」と問いながら進められます。

```
┌─────────┬────────────────────────────┐
│         │                            │
│    ●    ┄┄┄┄┄┄●                      │
│   単位円  │      ＼＿／￣＼            │
│         │                            │
└─────────┴────────────────────────────┘
   なぞる         なぞった分だけ描かれる
```

- 円の点とグラフの点を**点線でつなぐ**ので、「円の縦方向の値がそのままグラフの高さになる」ことが目で分かります
- 円の中に **x 軸からの角度を弧と矢印で示し、度数（60° など）を表示**します。x 軸は赤、y 軸は紺で、軸名も入れています
- θ 軸の目盛りは **π/4 刻み**。45°系（π/4, 3π/4 …）も読めます（隣と重なる分は自動で間引きます）
- **代表角（0°, 30°, 45°, 60°, 90°, 120°, 135°, 150°, 180°…）に吸い付きます**。狙った角でぴたりと止まるので、板書の値と突き合わせられます
- 範囲は **−π 〜 3π**（2周分）。教科書と同じで、「2π ごとに同じ形が繰り返される」ことを見せられます

## cos のときは単位円を90°回します

教科書と同じ扱いです。cos θ の値は点の **x 座標**なので、そのままでは横方向の量になり、グラフの縦方向と対応しません。**座標軸を90°回転させて、cos θ が縦方向に来るようにしています。**

これにより sin のときと同じく、円の点から水平に点線を引くだけでグラフの点に届きます。

## 授業での使い方（進行例）

**1. sin から始める**
θ = 0 から少しずつなぞらせ、点の高さ（y 座標）がそのままグラフの高さになることを確認します。

**2. 代表角で止める**
30°, 45°, 60°, 90° で止めて、値（0.500 / 0.707 / 0.866 / 1.000）が板書の 1/2, √2/2, √3/2, 1 と一致することを見せます。

**3. 1周させる**
360° まで回すと、グラフが1つの波を描き終えます。さらに回すと**同じ形が繰り返される**ことが見えます。

**4. cos に切り替える**
タブを押して cos に切り替え、**円が90°回っている理由**を説明します。同じように なぞると、1 から始まる波が描かれます。

**5. 2つを比べる**
タブを往復させて、sin と cos が同じ形で **π/2 だけずれている**ことに気づかせます。

## 操作

| 操作 | 方法 |
|---|---|
| 角を動かす | 左の円を指でなぞる（円の内側・外側どこでも可） |
| 角を直接指定する | 右のグラフ側をタップ・ドラッグ |
| sin / cos の切り替え | 上部のタブ |
| 吸着の入切 | 「代表角に止める」ボタン、または <kbd>S</kbd> |
| 描いた線を消す | 「なぞりを消す」ボタン（角はそのまま） |
| 全部やり直す | 「すべて初期化」ボタン |
| 細かく動かす | <kbd>←</kbd><kbd>→</kbd>（1°ずつ / Shift で15°ずつ） |

タッチ操作でもマウス操作でも同じように動きます。キーボードは PC のみです。

## 教室で使うときの設定

- **文字を大きく** — 1.0 → 1.3 → 1.6 倍。投影時は後方の席から読めるサイズに
- 明るい教室での投影を前提に、配色は白背景で固定しています

## 設計上の注意点

- **単位円の半径とグラフの振幅を同じピクセル数にしている。** これを揃えないと円の点とグラフの点が同じ高さに来ず、点線が水平に引けない。教材として最も重要な対応関係が崩れる
- **角は切り詰めない内部値を別に持つ。** 表示は −π〜3π に収めるが、ドラッグの基準に切り詰めた値を使うと、端まで回したあと指を動かしたときに大きく逆走する
- **吸着はいちばん近い代表角を選ぶ。** 配列を順に見て最初に見つかったものを返すと、45° が 30° に吸われてしまう
- **代表角は π/12 を単位とした整数で持つ。** `a % (π/4)` のような剰余で「π/4 の倍数か」を判定すると、15π/12 が π/4 の5倍にわずかに届かず剰余が π/4 の直前になり、**225°（5π/4）だけ取りこぼす**（135° と 315° は偶然ぴったり 0 になるため通る）。浮動小数点の剰余で角の一致を調べてはいけない
- **左余白は円の半径とは別に確保する。** cos では y 軸が左を向くため、余白が足りないと矢印とラベルが画面外に出る（実測で x = −2px）
- **円は1周しかないので、2π をまたぐと角度が飛ぶ。** 前回との差を ±π に収めてから積み上げ、連続して回せるようにしている
- **なぞって通過した範囲だけグラフを描く。** 最初から全体を描いてしまうと「自分で描いた」感覚が失われる
- **弧の角度は canvas 座標に変換してから描く。** canvas は y が下向きで数学の角と符号が逆になり、cos ではさらに軸を90°回しているため、`canvasAngle()` に集約して弧・矢印・ラベルすべてで共有している
- **代表角の印は黒。** 薄い灰色では投影すると見えない
